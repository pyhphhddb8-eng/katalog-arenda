# Каталог с подбором по параметрам

Демо-модуль каталога для сайта: аренда строительного инструмента. Подбор по
характеристикам — несколько групп чекбоксов, диапазон цены, сортировка — и
пересчёт цен по сроку аренды.

Вторая из семи новых работ для портфолио профиля FL.ru `kusaka63`.

## С чего начать

Читать `docs/superpowers/specs/2026-09-13-katalog-arenda-design.md` — там
решение целиком: данные и параметры, поведение списка, карточка позиции,
экраны, устройство кода, что проверяется и чего в модуле нет.

Дальше по порядку: план работ, сборка, предпросмотр со скриншотом, правки,
выкладка на GitHub Pages.

## Состояние на 13.09.2026

Дизайн согласован с владельцем. Кода нет.

## Зачем именно такой

На профиле `serhio2490` уже есть каталог: бытовые услуги, двенадцать позиций,
фильтр пятью кнопками-категориями. Новая работа отличается и нишей, и
механикой — иначе заказчик, открывший оба профиля, увидит дубль. Эскиз
сравнения «было / будет» лежит в
`~/Progects/fl-portfolio-perenos/sceny/sravnenie.png`.

## Решения, которые уже приняты

Объём — подбор и расчёт срока. Заявки, корзины и формы нет: они тянут за собой
персональные данные и 152-ФЗ, а это отдельная, четвёртая работа портфолио.

Стек — React, Vite, Tailwind. Здесь настоящее состояние: четыре независимых
регулятора вместе влияют на список и на цены. Один HTML-файл, как на лендинге
«Скуф-тур», отброшен: на чистом JS это дольше пишется и чаще ломается.

Отбор и расчёт цены живут отдельными чистыми функциями, не знающими про React.
Ошибки подбора прячутся именно там, а чистые функции проверяются тестами без
запуска браузера.

Данные позиций — отдельный файл списком, правится без программиста.
